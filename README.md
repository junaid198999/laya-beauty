# Laya Beauty

Brand website for [laya-beauty.com](https://laya-beauty.com) — Next.js App Router, ready for Vercel.

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Build

```bash
npm run build
npm start
```

## Deploy on Vercel

1. Import the `layabeautywebsite` folder (or this repo) in [Vercel](https://vercel.com).
2. Framework preset: Next.js (auto-detected).
3. Add domain `laya-beauty.com` and point DNS to Vercel.
4. Configure `hello@laya-beauty.com` with your email provider (not hosted by Vercel).
