# Laya Beauty

Brand website for [laya-beauty.com](https://laya-beauty.com) — **LAYA GLOW TRIO** (Glass Lip Oil, Dew Flush, Light Drop). Next.js App Router, ready for Vercel.

## Develop

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Routes

- `/` — Brand story, collection, ritual, founder, contact
- `/products/glass-lip-oil`
- `/products/dew-flush`
- `/products/light-drop`

## Build

```bash
npm run build
npm start
```

## Deploy on Vercel

Import this repo in [Vercel](https://vercel.com), add domain `laya-beauty.com`, and configure email separately for `hello@laya-beauty.com`.
